    What is Saya no Uta (The Song of Saya)?

    Saya no Uta is a love story. A story about finding someone who makes the world beautiful again, even when everything else seems wrong.

    If love changes the way we see the world, which vision is true?
    If only one person kind to you in this cruel world, How will you respond to her love? And if love asks you to look away, what might you miss?

    There is only one way to find out. Play Saya no uta for yourself, and discover what love really means through this legendary love story in visual novel world.

    Buy this game on GOG or Steam.

    Download And Install

    Download at: Nekogui Project

    Installation is simple. The same as my previous mods, extract downloaded ZIP, and drop it in the game folder. And run the game from "Nekogui Launcher.exe".

    Current features

    • Reads dialogue and supported interface text aloud through Prism.
    • Announces supported choices and lets you navigate menus with the keyboard.
    • Includes a launcher with mod-language selection (English and Japanese).

    Known limitations

    • The Load menu works, but its navigation and presentation are still rough.
    • During gameplay, selecting an exact save slot to load is not yet fully supported.
    • Choice dialogue near the end of the game has not been fully verified.
    • The game is not fully tested, and sometimes random crash may occered. Please be careful, and save more often.

    Keyboard controls

    • Arrow keys — Navigate available menu items and choices.
    • Enter — Confirm a selection or advance dialogue.
    • Backspace — Go back or cancel where supported.
    • S — Save.
    • L — Load latest slot.
