# That time I got reincarnated as a blind anime character in skyrim: A guide to turn your skyrim to anime

Do you dream to reincarnated in another world like protagonist in anime you like? here the guide for you.

This cover how to install custom race, clothing, follower, graphical enhancement, voice packs and weapon. In future may including mod that change gameplay too. So this is very a long and rather complex guide for beginner, but your heart ask for anime, aqua goddess will bless you on this wonderful world!

## Requirements

* *[CBBE / 3BA](https://www.nexusmods.com/skyrimspecialedition/mods/30174)**, 
This one isn't hard to install, but you need to remember perfectly what option you choose during installation. A curvy body or slim body for example.
* **[Caliente's Beautiful Bodies Enhancer CBBE](https://www.nexusmods.com/skyrimspecialedition/mods/198)**, 
This one replaces all vanilla female body, and extend to the original CBBE, so it's another hard requirement. There is a safe for work version to download as well, if you're uncomfortable to use, please go to grab that one.

* **[CBPC - Physics with Collisions](https://www.nexusmods.com/skyrimspecialedition/mods/21224)**, 
This is a body physics, well it's rather focus on virtual and NSFW, but I found many CBBE / 3BA clothes require for some reasons, to avoid problem please in stall it as well.

* **[Faster HDT-SMP](https://www.nexusmods.com/skyrimspecialedition/mods/57339)**, 
This is clothes and hair physics, when you run around or the wind pass you, your clothes will move like the real clothes or hair in real life. not a hard requirement, because many clothing mod offer a static clothes without physics. And this can increase CPU usage, keep in mind. but I installed it any way.
