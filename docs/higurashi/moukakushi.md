# Moukakushi Project | Higurashi Hou Accessibility Mod By ON1XN

**Moukakushi** (盲隠し) is an accessibility mod for Higurashi no naku koro ni hou a visual novel on Steam and GOG. Read carefully and find answer for your curious questions.

## Current Features

- Story text, choices, menus, and confirmation questions.
- Navigate supported menus and settings with a keyboard or controller.
- Save, load, overwrite, or delete saves with clearly named actions and slots.
- Repeat dialogue or revisit the last 50 spoken entries.
- Switch between automatic and manual reading.
- Pause and resume announcements.

Support for additional chapters and remaining menus is still being explored. It's public test after all.

## Download And Installation

Download at: [Moukakushi](https://drive.google.com/drive/folders/1FfuDbdrqtIo1E8PmBTZt80e2rScM2kuJ?usp=sharing)

> **Note:** Download for Episode 1 - 8, Rei and Plus separately. Since the game treat them differently. However, all function are the same.

Then extract ALL the contents of this ZIP directly into the game
folder, beside the game executable. Keep the folders intact.

The game folder should contain winhttp.dll, doorstop_config.ini and BepInEx.

And install a separate copy into each episode's own game folder.

## CONTROLS

Enter: advance dialogue or activate a menu selection.
Space: repeat the last spoken dialogue without advancing.
Left bracket / right bracket: previous / next speech-history entry.
Shift with either bracket: first / last history entry. History holds 50 entries.
Alt+A: toggle native Auto/Manual text mode.
Escape: pause the story, or cancel/back in a supported menu.
Up/Down: choose a menu item or slot.
Left/Right: adjust a setting, choose a slot action, or change the selected page.
Page Up/Page Down: change save/load page.
